RAW DATA

The data comes from the Deportation Data Project:
https://deportationdata.org/data/processed/ice.html

We used its release of Aug. 24, 2026, which covers Oct. 1, 2022, through Aug. 6, 2026.
Put these four files in this folder before running the notebook:

- arrests-latest.parquet                          (35 MB)
- detainers-latest.parquet                        (25 MB)
- joined-arrests-detention-stays-latest.parquet   (97 MB)
- detention-stints-latest.parquet                 (272 MB, too big for GitHub; download it)

Download links:
  https://media.githubusercontent.com/media/deportationdata/ice/main/data/arrests-latest.parquet
  https://media.githubusercontent.com/media/deportationdata/ice/main/data/detainers-latest.parquet
  https://media.githubusercontent.com/media/deportationdata/ice/main/data/joined-arrests-detention-stays-latest.parquet
  https://media.githubusercontent.com/media/deportationdata/ice/main/data/detention-stints-latest.parquet

The project replaces these files when it publishes new data, so a later download may give slightly different numbers.
